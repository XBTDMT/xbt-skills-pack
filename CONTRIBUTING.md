# Contributing

Issues are welcome. Pull requests are not: every file here is generated from a private source, and the next release overwrites the tree. A change made only in this repository would be erased.

Open an issue for a bug, a wrong instruction, a step that fails on your machine, or a case the behaviour suite should cover. If a graded run disagrees with the numbers in the README, attach that run folder's `grades.json` and the models you used.
